# AI Improvement Record

## Original Development

Explain how you developed the original version and describe any AI assistance used before the first required commit. AI use during this stage should be minimal.
For the original version I thought about what I wanted in my app and what useful features I could add to bring value.
From there, I broke down every feature I wanted into a list on a sticky note, and started coding. I continuously ran the code to affirm that it was running properly.
AI was used to explain the use of displaying the data from the alternative file as I was having trouble listing all the data.

## AI Tools Used

List each AI tool used while improving the application.
I used Gemini and Claude. No specific agent inside, just regular chats.

## Improvements Requested

Describe the important prompts or requests you gave the AI. Do not paste a complete chat transcript.
I copy and pasted the whole code, then asked for improvements. When given improvements that I did not want to add, I asked for a different result.

## Changes Accepted

For each major accepted change, explain what changed, why you accepted it, and how you verified that you understood it.
The most major changes were naming errors, formatting bugs, and option mismatches. I accepted all of these changes as they were items that I simply carelessly forgot to doublecheck.
I understood the changes and asked for additional information if I didn't understand something completely.

## Changes Rejected or Revised

Describe any AI suggestion you rejected or modified and explain why.
I rejected several changes involving downloading packages as I didnt want to have to deal with that in the readme file nor github.
The simpler changes that cleaned up the code I accepted as it was still my original code, just polished.

## What I Learned

Explain what you learned by reviewing and applying the AI-assisted improvements.
The more I use AI the stupider it seems to be. With specific prompting, it is mainly correct but almost always missing additional context or cohesiveness.
Other times, it will simply hallucinate and try to convince you something that is correct. This happened several times while coding.
